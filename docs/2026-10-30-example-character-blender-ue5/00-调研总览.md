## 目的

用一个可以在本机重跑的小案例，完整展示 research → FEV → DOCS → Promotion → OpenSpec → production → ICD。角色由脚本生成，因此模板不带任何外部模型、贴图或动画。

## 范围

- Blender 5.1 `--background`：生成角色（18 bones、rigid skinned mesh、2 shape keys、2 material slots、30 帧 action）并导出 FBX。
- UE5.8 isolated AIAGENT Worker（`-NullRHI`）：自动 import 并 readback。
- 非目标：rendering、physics、Control Rig、retarget、texture。

## 核心结论

1. **FEV Root `example-char`：FEASIBLE**（scope 为 `unit_cm`）。见 [aggregate report](../../pipelines/graphs/example/example-character-export-fev/aggregate/report.md)。
2. **关键 Negative Finding**：scene 以 m 为单位导出时，UE 把 unit factor 100 写入 `root` bone scale；只比较 bone 位置无法发现这个问题。改为 `scale_length` 0.01 + cm 数据后，所有 bone scale 为 1。
3. 次要 Finding：Blender re-import 后 action 起始帧晚 1 帧、take 名称不保留；下游只依赖 frame length。
4. **ICD：L3 PASS**（Run `2026-10-30T155119`，13/13）。L4 未声明，因为 Blender / UE runtime check 没有进入 CI。

## 如何在新机器上重跑

1. 按 [local-environment](../local-environment/AGENTS.md) 发现 Blender 5.1 与 UE5.8，确认 AIAGENT Worker 账户可用。
2. 复制 [`environment.example.yaml`](../../pipelines/_shared/host_run/environment.example.yaml) 到 `.local/environment.yaml` 并填写。
3. 依次运行 FEV 的两个 Sub-FEV，再运行 ICD Graph（命令见各 `pipeline.md`）。新的 Run 只证明新机器上的结果；本 Topic 的 Run identity 只来自原始示例机器。
